## Idioma, foco y selector

El componente instalado usa español por defecto: semana desde el lunes, encabezados `L M X J V S D` y nombres completos de mes. `locale` y `formatters` permiten sobrescribir esta configuración.

`initialFocus` se admite como alias de `autoFocus`; si se especifican ambos, prevalece `autoFocus`. El selector de mes/año ya forma parte de la API: usa `captionLayout="dropdown"` con `startMonth` y `endMonth` para delimitar el intervalo. El encabezado predeterminado sigue siendo `label`.

```tsx
<Calendar mode="single" captionLayout="dropdown"
  startMonth={new Date(2020, 0)} endMonth={new Date(2030, 11)}
  initialFocus />
```
