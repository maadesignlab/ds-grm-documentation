## Compatibilidad de composición

`render` sigue siendo la API de Base UI. Para consumidores que usan composición Radix, `PopoverTrigger asChild` acepta un único elemento React y conserva sus eventos y referencias. No debe combinarse con `render`.

`PopoverAnchor` permite una referencia visual independiente dentro del mismo `Popover`; admite `asChild` y `ref`. Usa un solo Anchor por Root. El propio Anchor no abre el popup. `PopoverContent anchor` tiene prioridad sobre ese Anchor; sin ninguno, se usa el trigger. `collisionPadding` se transmite al posicionador de Base UI.

`onOpenAutoFocus` y `onCloseAutoFocus` reciben un evento cancelable de compatibilidad. `preventDefault()` impide el movimiento automático de foco. Si no se cancela, se respeta `initialFocus` o `finalFocus`, respectivamente, y después el comportamiento predeterminado de Base UI. Estos eventos no son eventos DOM despachados sobre el elemento.

```tsx
<Popover>
  <PopoverAnchor asChild><div ref={anchorRef}>Referencia</div></PopoverAnchor>
  <PopoverTrigger asChild><Button>Abrir</Button></PopoverTrigger>
  <PopoverContent onOpenAutoFocus={(event) => event.preventDefault()}>
    Contenido
  </PopoverContent>
</Popover>
```

El portal conserva `container` para composiciones dentro de Sheet. Esta compatibilidad cubre las propiedades descritas; no convierte toda la API de Radix en Base UI.
