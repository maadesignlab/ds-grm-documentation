# Releases

El paquete inicia en `1.0.0`, alineado con la release inicial V1 indicada en la portada de Figma.

| Cambio | Versión | Ejemplo |
| --- | --- | --- |
| Corrección compatible | patch | Ajustar contraste de Badge |
| Nueva capacidad compatible | minor | Añadir variante a Spinner |
| Cambio incompatible | major | Renombrar una prop pública |

Ejecuta `npm run changeset` por cada cambio visible. El resumen debe identificar su alcance: `Badge: agrega variante info outline`.
