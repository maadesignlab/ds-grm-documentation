# Design System Grupo Reina Madre

Implementación web del archivo **Design System GRM v1**. Figma define la organización, tipografía, tokens, variantes y criterios visuales. shadcn/ui proporciona la base abierta y editable de los componentes React.

## Organización

- **Foundations:** tokens, tipografía e iconografía.
- **Components:** una entrada por página de componente de Figma.
- **Releases:** cambios versionados con SemVer y Changesets.

## Contrato de sincronización

1. El cambio visual se aprueba primero en Figma.
2. Se actualizan tokens o componentes sin reemplazar la API de shadcn innecesariamente.
3. Se actualizan stories, pruebas y accesibilidad.
4. Se crea un changeset que comienza con el nombre del componente.
